# 🌍 VOYARA

> Your intelligent travel companion.

VOYARA is a smart tourism platform designed to help travelers discover destinations, understand their surroundings, plan their trips, and communicate more easily while traveling.

## ✨ Features

### 🌎 Interactive World Map
Users can explore the world map and select a country and city to begin their travel experience.

### 🏙️ Destination Dashboard
After selecting a destination, users can access useful information about the selected city, including:

- City information
- Current weather
- Travel conditions
- Recent local news
- Important events and alerts
- Travel safety information
- Best time to visit

### 🛡️ Travel Safety & Situation
VOYARA provides information about important situations that may affect travelers, such as:

- Natural disasters
- Earthquakes
- Floods
- Major incidents
- Conflicts
- Transportation disruptions
- Flight conditions
- Travel warnings

> Safety information should always be verified through official and trusted sources before making travel decisions.

### 💰 Travel Costs
A dedicated travel planning section helps users estimate the cost of their trip.

Users can explore:

- Hotel prices
- Food expenses
- Transportation costs
- Attraction fees
- Activity costs
- Daily travel expenses
- Estimated total trip budget

### 🏨 Hotels
Users can discover and compare hotels based on:

- Location
- Price
- Rating
- Facilities
- Distance from attractions

### 🏛️ Historical & Cultural Places
VOYARA helps travelers discover:

- Historical sites
- Monuments
- Ancient places
- Cultural landmarks
- Museums
- UNESCO heritage sites
- Important buildings

### 🎢 Entertainment & Recreation
Users can discover recreational activities such as:

- Amusement parks
- Parks
- Zoos
- Gardens
- Ski resorts
- Racing tracks
- Horse riding
- Adventure activities
- Outdoor experiences

### 🤖 AI Visual Travel Assistant
Users can upload or take a photo of an unknown object, building, monument, artwork, or historical place.

The AI can analyze the image and provide information about what the user is seeing.

This can also help users discover places or objects that are not already listed on the platform.

### 💬 AI Travel Chatbot
VOYARA includes an AI-powered travel assistant that can answer questions about destinations, attractions, transportation, activities, costs, and travel planning.

### 🎙️ Voice Assistant
Users can communicate with the travel assistant using their voice instead of typing.

### 🌐 Translation
VOYARA provides translation assistance for travelers.

Users can:

- Translate text
- Translate spoken language
- Communicate with local people
- Receive translated responses

The goal is to make communication easier while traveling in another country.

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Bootstrap
* REST APIs
* AI APIs
* Maps APIs
* Weather APIs
* News APIs

## 🔐 Security

API keys and other sensitive credentials should never be exposed directly in frontend JavaScript.

Sensitive API credentials should be stored securely using environment variables and a backend/proxy when required.

## 📱 Responsive Design

VOYARA is designed to provide a responsive experience across:

* Desktop
* Laptop
* Tablet
* Mobile

## 🎯 Vision

VOYARA aims to bring travel discovery, planning, real-time information, AI assistance, image recognition, and translation together in one intelligent platform.

### Discover. Plan. Explore. Communicate. Travel.
